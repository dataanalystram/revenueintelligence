## 4. Result

- **Contradictions found and fixed:** 4.
  1. Signal types as MINOR canonical versions, which conflicted with the registry.
  2. AccountContext "membership rule" vs 0..1 context per line.
  3. Recommendation failing a hard P3.
  4. Hierarchy depth stated as semantics.
- **Underspecification fixed:**
  - `agreement_ref`;
  - line ↔ Contract over time;
  - Opportunity lines;
  - outcomes terminology;
  - raw-value paths;
  - 18 missing matrix rows.
- **No implementation change.** Mechanical checks pass after the corrections: 5/5 diagrams render, 0 broken links,
  prettier passes.
- The candidate remains a **candidate**. It is not v1.0, and M9C/M9D remain the required pressure tests before the
  freeze.
- **Not checked by E11, left for E12 and later:**
  - independent adversarial review (E12);
  - physical table designs, which are deliberately out of scope;
  - whether GitHub's own Mermaid renderer matches mermaid-cli 11.4.2. GitHub currently bundles a Mermaid 10/11
    renderer; the syntax used is standard.
