# Canonical Architecture v1 Candidate — E1: Canonical inventory (M9E-A)

Part of the [Canonical Architecture v1 Candidate](CANDIDATE.md). Status: **candidate for review**. Nothing here is
implemented unless it is labelled `IMPLEMENTED TODAY`.

## Status labels

| Label                       | Meaning                                                                                                      |
| --------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `IMPLEMENTED TODAY`         | Code, schema and tests exist on `main` (`a9c0133`)                                                           |
| `DOMAIN-ONLY`               | A Zod schema / pure function exists in `apps/api/src/modules/domain`, nothing persists or uses it outside it |
| `PROPOSED FOR V1 CANDIDATE` | Specified by this candidate; not built                                                                       |
| `DEFERRED`                  | Recognised, intentionally not specified in detail for v1 (reason given)                                      |

Layer column: **Core** (always available), **Module** (optional reusable business module), **Extension** (tenant
data governed by the extension framework), **Platform** (cross-cutting infrastructure, not a business noun),
**Derived** (computed view, not stored as truth), **Rejected**.
